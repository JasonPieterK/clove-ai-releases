# Clove AI releases

Android APK downloads for [Clove AI](https://cloveai.360framed.com), a free AI expense tracker and budget app for Android and the web. Source code is private.

Clove AI lets you log spending by typing, talking or scanning a receipt, set budgets, and ask an AI money coach about your own totals. It never connects to a bank, and the AI is optional and off until you turn it on. It is made by one independent developer in Indonesia.

## Install on Android

1. Open the [download page](https://cloveai.360framed.com/get-app), or take `clove-ai.apk` from the latest release here.
2. Allow installing from this source when Android asks, then open the file. Needs Android 7.0 or newer.

A Google Play listing is planned but not live. When it is, moving to it means uninstalling the APK version first, because the two are signed with different keys.
